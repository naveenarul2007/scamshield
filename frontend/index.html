About ScamShield

Project documentation, architecture, and technology stack built for ALGOTHON’26.

The Problem

Digital scams have exploded in scale and sophistication across India and globally. Cybercriminals exploit urgent psychological triggers—threats of blocked bank accounts, electric power cuts, fake lottery prizes, and deceptive work-from-home tasks. Ordinary citizens and elderly users struggle to distinguish legitimate bank notifications from malicious phishing vectors.

The Solution

ScamShield provides an instant, unified cyber-defense platform capable of analyzing SMS, WhatsApp messages, emails, URLs, and uploaded screenshots. Unlike opaque black-box checkers, ScamShield prioritizes Explainable AI—providing clear, transparent risk point breakdowns so users learn exactly which indicators (urgency, OTP requests, suspicious TLDs, typosquatting) triggered the alert.

Technology Stack

  • Backend Engine: Python, Flask REST API with structured JSON responses
  • Machine Learning: scikit-learn (TF-IDF N-Gram Vectorizer + Calibrated Logistic Regression, 95.65% Accuracy, 100% Recall on scam test set)
  • Heuristic Rules Engine: Configurable weighted scoring engine evaluating 12 distinct threat vectors
  • OCR Pipeline: Tesseract OCR integration with graceful fallback for sample datasets
  • Database Layer: SQLite / PostgreSQL / Supabase ready via SQLAlchemy
  • Frontend: Clean Vanilla JavaScript, Semantic HTML5, Custom Cybersecurity Design System, Chart.js

Important System Limitation & Disclaimer

ScamShield is an assistive decision-support tool designed to highlight risk indicators. It cannot guarantee that any content is 100% safe or malicious. Users must always verify transactions through official bank channels, apps, or in-person verification.
